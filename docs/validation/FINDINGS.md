# Validation findings

Generated by the post-restructure verification pass.

## Detection (`validate_detection.py`)

| Config | Result | Notes |
| --- | --- | --- |
| `default` (`demo.gif`) | Pass | YOLOv8 loads, inference runs, SORT tracks objects |
| `cars4` | Skipped | `assets/media/cars4.mp4` not bundled |

Observed behavior on `demo.gif`:

- Clip is only **6 frames** at **1000×584**
- ROI mask `assets/media/mask.png` is **1280×720** → dimension mismatch; mask is skipped with a warning
- Detections are produced (dozens of boxes across the short clip)
- Line-crossing counts can stay at zero on this short GIF because tracks need several hits and vehicles may not cross the configured lines within 6 frames
- Adaptive green times correctly fall back to the configured base (30s) when lane counts are empty

Bottlenecks / accuracy notes:

- CPU inference on YOLOv8n is adequate for demos but slow for real-time multi-camera junctions
- Count-line coordinates in config are tuned for wider junction footage; recalibrate for new cameras
- Prefer a longer MP4 (e.g. `cars4.mp4`) for meaningful counting validation
