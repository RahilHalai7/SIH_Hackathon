# Assets

Central store for runtime media used by detection and simulation.

```text
assets/
├── images/     # Intersection background, directional vehicle sprites, signal icons
├── media/      # Demo GIF / optional MP4 clips / ROI masks
├── models/     # YOLO weight files
└── output/     # Sample annotated screenshots
```

See the README files inside `media/` and `models/` for optional large files that are not shipped in git.
