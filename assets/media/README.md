# Media assets

| File | Purpose |
| --- | --- |
| `sample_video.mp4` | Default 1280×720 highway clip (`config/detection/default.yaml`) |
| `sample_video_2.mp4` | 1920×1080 urban junction clip (`config/detection/sample_video_2.yaml`) |
| `demo.gif` | Short 6-frame demo leftover from the original project |
| `mask.png` | Optional ROI mask for older 1280×720 clips |
| `cars4.mp4` | Optional extra clip for `config/detection/cars4.yaml` |

Large MP4 files are gitignored. Keep them locally under `assets/media/` to run detection.
